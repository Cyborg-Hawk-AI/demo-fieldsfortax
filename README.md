# FieldsForTax

> Custom-field client data layer that plugs into TaxDome or any tax CRM via CSV sync.

## What is FieldsForTax?

FieldsForTax is built for **Tax preparers already using TaxDome, Canopy, or similar tools who supplement with spreadsheets to track custom client data**. Hyper-specific to tax data vocabulary — ships with pre-built field templates that a generic tool like Airtable never will, reducing setup friction to near zero

### Core MVP features
- Unlimited custom fields per client (dropdowns, checkboxes, numeric, date, text)
- Pre-built tax-specific field templates (dependents, carryover losses, entity type, filing status, prior-year AGI)
- Two-way CSV import/export compatible with TaxDome and Canopy client lists
- Per-client data change history/audit log
- Bulk field update via spreadsheet paste

**Pricing:** Flat monthly SaaS, per-firm pricing at $29/month flat per firm (unlimited clients, unlimited fields); annual plan at $290

## Local development

### Prerequisites

- Node.js 18.17 or later
- npm 9+ (comes with Node)

### Setup

```bash
npm install
```

### Development server

```bash
npm run dev    # http://localhost:3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser. Key routes:

| Route | Description |
|-------|-------------|
| `/` | Landing page — hero, features, pricing, CTA |
| `/demo` | Interactive product mock — all MVP features, fully populated |
| `/developers` | Feature documentation — what's mocked vs production |
| `/research` | Origin story, validation checklist, source pain points |

### Production build

```bash
npm run build  # required before deploy
npm start      # serve production build locally
```

### Deploy to Vercel

Push to a Git repository and import into Vercel, or run `vercel` from this directory. No environment variables, custom server, or rewrites are required — the app deploys with zero configuration.
